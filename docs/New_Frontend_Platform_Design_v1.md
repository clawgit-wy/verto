# 新前端应用管理平台（AI & Low-Code 赋能版）需求设计方案

## 1. 方案背景
当前公司前端开发基于 **Vue 3 + Vite + Spring Boot 2**。为了在不触动核心业务稳定性的前提下，引入 **JeecgBoot 3.9.2** 的 AI 与低代码生产力，本项目旨在构建一个集“应用管理、效能工具、AI 调度”为一体的研发门户。

---

## 2. 核心架构设计

### 2.1 整体架构
- **底座**：基于 JeecgBoot 3.9.2 搭建。
- **AI 引擎**：中转调用大模型（OpenRouter/Ollama），集成 Jeecg AI 逻辑。
- **Skill 中枢**：实现 MCP (Model Context Protocol) 协议，作为 Claude Code 的上下文供应源。

### 2.2 核心流程
1. **开发者** 通过平台获取 AI Skills 配置。
2. **本地 IDE (Claude Code)** 通过 MCP 协议连接到本平台。
3. **平台** 将公司私有业务规范（Skill）注入 AI，实现精准代码生成。

---

## 3. 功能模块规划

### 3.1 AI 开发者中心 (AI Developer Hub)
- **Skill 资产库**：
    - 集成 [Jeecg Skills](https://jeecg.com/skills)，涵盖 Online 表单、代码生成等官方能力。
    - **自定义业务 Skill**：针对公司公交/客车业务逻辑编写私有 Skill。
- **Claude Code 配置导出**：一键生成 `mcp-config.json`，支持本地 IDE 快速接入。

### 3.2 低代码公共服务 (Low-Code Services)
- **对话式出码 (Chat2Code)**：输入自然语言，产出符合公司规范的 Vue 3 组件。
- **Schema 转换引擎**：解析 SQL DDL 语句，自动生成前端 Online 列表和表单 JSON 配置。
- **可视化沙箱**：实时预览 AI 生成或低代码配置的 UI 页面。

### 3.3 业务管理迁移 (Existing Business)
- **前端应用管理 (V2)**：
    - 记录各应用技术栈、代码仓库。
    - **应用级 Skill**：为每个应用定义专属的 Prompt 模板。
- **前端人员列表 (V2)**：
    - 管理开发人员权限。
    - **AI 效能看板**：量化统计 AI 生成代码量及工时节省情况（绩效支撑数据）。

---

## 4. 技术实施路线图

### 第一阶段：基础设施与 AI 核心 (Month 1)
- 部署 JeecgBoot 3.9.2 环境。
- 调通 AI 接口，实现 Web 端的“对话生代码”原型。
- 部署基础 MCP Server，支持 Claude Code 连接。

### 第二阶段：业务平移与 Skill 增强 (Month 2)
- 将旧平台的“应用管理”与“人员列表”功能重构并迁入。
- 编写“公司通用代码规范 Skill”，解决 AI 生成代码风格不一的问题。

### 第三阶段：全流程覆盖 (Month 3)
- 推出“在线代码医生”，支持对存量老代码的 AI 分析与重构建议。
- 完善效能看板，产出首份《AI 研发效能提升报告》。

---

## 5. 绩效汇报点建议
1. **架构创新**：引入 MCP 协议，打造公司级 AI Skill 调度中心，使 AI 具备业务“上下文”。
2. **提效显著**：通过“Skill + Claude Code”模式，将标准业务模块的开发周期缩短 40% 以上。
3. **资产沉淀**：将零散的开发经验转化为可被 AI 调用的“Skill 资产”，实现技术标准的强制落地。
